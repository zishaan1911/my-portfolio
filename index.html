01

Helmsman

v1.0.0

GitOps deployment with an AI risk gate and self-healing rollback. Push code, and Helmsman containerizes it, renders the manifests, reviews the risk and commits the change for ArgoCD or Flux to roll out.

  • Seven small Go CLIs that run in CI and as a cluster CronJob. Nothing calls the Kubernetes API to make a change: every deploy is an auditable, revertible Git commit.
  • AI is used in exactly two places, risk review on top of static policy checks and plain-English root-cause analysis. Both fall back to deterministic output when the model is unreachable.
  • Rollback is a git revert triggered by health rules, never a model decision.
  • 85.7% test coverage
  • 0 dependencies
  • 7 CLIs, one image

Vector

C++20

A real-time simulator for autonomous interception: physics, noisy sensing, Bayesian state estimation, guidance and control composed into one closed loop.

  • A constant-velocity Kalman filter tracks the target through Gaussian noise and dropped detections, and its covariance is drawn as a true uncertainty ellipse.
  • True proportional navigation and pure pursuit behind one interface, with an iterative intercept-point predictor and a jerk-limited actuator model.
  • Headless Monte Carlo runner: up to 50,000 deterministically seeded trials per batch, scoring success rate, miss distance and robustness to sensor noise.
  • 74.3% intercept rate vs evasive targets
  • 50,000-trial batches
  • 120 Hz RK4 physics

Kerrscope

v1.1.0

A real-time Kerr black hole ray tracer. Gravitational lensing isn’t a screen-space effect here: every pixel’s photon path is integrated through curved spacetime on the GPU.

  • Integrates Hamilton’s equations for null geodesics in the Kerr metric with RK4, using analytic derivatives of the inverse metric, inside an OpenGL 3.3 fragment shader.
  • Accretion disk with redshift, Doppler shift and beaming, orbiting bodies lensed into thin arcs, and black-hole spin adjustable live.
  • Runs on GPUs as old as Intel HD 4000. Static release binaries for Linux and Windows, with published SHA-256 checksums.
  • 1 geodesic per pixel
  • OpenGL 3.3 no compute shaders

R1

How Long is the Graph of xⁿ?

Logarithmic corner defects in arc length · Z. Ahmed · preprint, Zenodo, 2026

As n → ∞ the graph of y = xⁿ on [0, 1] turns into a corner, so its length tends to 2. The paper works out exactly how fast.

L(n) = ∫₀¹ √(1 + n²x²ⁿ⁻²) dx  ⟶  2

2 − L(n) = (ln n + 1 − ln 2)/(n − 1) + O(ln²n / n²)
  • An exact, rapidly convergent Gamma-function formula for L(n), derived from a single Beta integral.
  • Corners of any turning angle θ: the coefficient of (ln n)/n is 2 sin²(θ/2).
  • By contrast the squircle |x|ᵖ + |y|ᵖ = 1 has no logarithmic term. Every numerical claim is recomputed by a script.
  • asymptotic expansion
  • Beta & Gamma functions
  • Mellin transform
  • mpmath

A Hybrid Learning Framework for Automated SAT Solver Selection

Z. Ahmed and T. Kwan Lee · research proposal, Zenodo, 2026 · Final Year Project, UTAR

Per-instance SAT solver selection that fuses handcrafted SATzilla-style features with graph-neural-network embeddings of the literal–clause graph, and measures what each representation actually contributes.

  • The feature-only selector closes 73% of the gap between the single best solver and the virtual best on SAT18-EXP.
  • The graph branch is 28× cheaper to compute than SATzilla’s probing features.
  • Pre-registered paired significance tests, family-held-out folds and nested-CV tuning, with negative results reported as plainly as positive ones.
  • PyTorch
  • graph neural networks
  • ASlib
  • CDCL solvers
